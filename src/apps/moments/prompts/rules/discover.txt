## Discovery Contract

Return only ideas that pass all four gates:

- Future use: the activity shows a likely upcoming decision, meeting, deadline, research step, design step, or recurring workflow.
- Bounded artifact: one focused output would help with that use in a single execution run.
- Grounded evidence: the idea is supported by one dense work signal, an explicit commitment/deadline, or several converging sparse signals.
- Executor handoff: the evidence and artifact shape give the executor a concrete place to start.

Select ruthlessly. Return 0-2 ideas per chunk, merge adjacent outputs that serve the same future use, and mark isolated sparse leads `weak` rather than inflating them into moments.

Do not chain separate signals into one story unless the activity explicitly connects them. If two events point to different future uses, keep the stronger one or return separate ideas.

Use tools only for targeted context that changes the usefulness, grounding, or scope of an idea. Evidence should be factual prose with pointers; `source_paths` should contain only pointer strings.

Set `cadence_hint` only when it is obvious: `once` for situational artifacts, `scheduled` for recurring reviews or digests, and `trigger` for condition-based moments.
