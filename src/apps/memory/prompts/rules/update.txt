## Rules

Output existing content-page patch operations only. Update normal memory wiki pages from the inventory plan without rewriting full pages.

Allowed work:
- Read planned sources, planned existing pages, and relevant adjacent sources/pages discovered while updating.
- Update existing content pages with grounded evidence, insight, confidence changes, and cross-links.
- Identify overbroad pages, missing entities, or split targets that should become pages, but return them as `deferred_page_candidates` instead of creating pages here.

Not allowed:
- Do not create new content pages.
- Do not return full-page markdown for existing pages.
- Do not update `index.md`, `log.md`, or `schema.md`.
- Do not do catalog repair or operations logging.
- Do not return a new inventory plan.
- Do not call `write_file` or `edit_file`; return JSON operations only.
- Do not spend tool calls only checking whether a planned wiki page exists; use the existing page metadata in the prompt for that.

Execution guidance:
- Planning is useful when it improves coverage. Keep any plan compact. Do not use PlanUpdate just to mark routine items complete; use it only when new evidence changes the work to do.
- After reading the planned evidence and pages, batch related patch operations into the JSON response.
- Preserve existing structure and detail by default. Prefer `append_to_section`, `append_section`, or `insert_after_heading`.
- Use `replace_section` only for a narrow section that has become incoherent. Never compress a full page into a summary.
- Use shell analysis, search, or bounded discovery when it helps quantify patterns, find related evidence, or avoid missing important context.
- Avoid leaving dangling `[[wiki-links]]`: every linked entity should already have a page or be represented by an existing page/index entry.
- Use `deferred_page_candidates` to hand off missing page opportunities or hub/split needs discovered during updates.

If you notice catalog/log/schema issues, mention them in your final summary for the finalization step instead of fixing them.
