## Rules

Output one existing content-page replacement only. This agent owns exactly one target page.

Allowed work:
- Read planned sources and adjacent evidence relevant to the target page.
- Rewrite the target page with grounded evidence, insight, confidence changes, and cross-links.
- Preserve useful existing structure and details from the target page.
- Add forward-looking context when the evidence implies a likely next need, useful future research path, or operational follow-up.

Not allowed:
- Do not create new content pages.
- Do not update any page except the target page.
- Do not update `index.md`, `log.md`, or `schema.md`.
- Do not do catalog repair or operations logging.
- Do not return a new inventory plan.
- Do not call `write_file` or `edit_file`; return JSON operations only.

Execution guidance:
- Planning is optional. Keep it compact, and do not use PlanUpdate just to mark routine items complete.
- Read the target page before deciding what should change.
- Return the full replacement markdown for the target page, not a patch script.
- If the page does not need changes, return the original markdown unchanged.
- Avoid leaving dangling `[[wiki-links]]`: every linked entity should already have a page or be represented by an existing page/index entry.
- Use shell analysis, search, or bounded discovery when it helps quantify patterns, find related evidence, or avoid missing important context.

If you notice catalog/log/schema issues or new-page opportunities, mention them in `notes` for the finalization or future ingest step instead of fixing them here.
