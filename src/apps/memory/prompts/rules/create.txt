## Rules

Output at most one new content-page create operation. This agent owns exactly one candidate page.

Allowed work:
- Create one normal memory wiki page when the candidate is grounded and distinct.
- Create a low-confidence starter page when the candidate has enough evidence for one useful paragraph.
- Add `[[wiki-links]]` to existing represented pages when natural.
- Skip the candidate when it duplicates an existing page, lacks evidence after reading, or would be misleading.
- Include forward-looking context when the evidence implies a likely next need, useful future research path, or operational follow-up.

Not allowed:
- Do not update existing normal content pages.
- Do not update `index.md`, `log.md`, or `schema.md`.
- Do not do catalog repair or operations logging.
- Do not call `write_file` or `edit_file`; return JSON operations only.

Execution guidance:
- Read evidence for this candidate before writing.
- Keep the page compact but useful: facts, category, why it matters, confidence, links, and likely future relevance.
- Include the best-fit `category` in frontmatter, using `notes` only when no stronger category fits.
- Use source dates exactly as provided in evidence.
- Avoid dangling `[[wiki-links]]`; link only to represented pages.
